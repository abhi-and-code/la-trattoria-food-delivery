# la-trattoria-food-delivery

## Full-Stack Food Delivery Platform

A full-stack food ordering web application built with **React, Node.js, Express, and MariaDB**, providing menu browsing, cart management, order processing, authentication, payment workflow simulation, and automated receipt generation.

La Trattoria provides an end-to-end food ordering experience through a responsive web interface.

Users can browse available menu items, manage their cart, place orders, and review their order history. The backend exposes RESTful APIs for authentication, menu management, and order processing.
